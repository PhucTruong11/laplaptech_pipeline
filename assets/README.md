# Assets

Thư mục dành cho screenshot và hình export khi cần minh họa portfolio. Hiện data flow được viết bằng Mermaid trực tiếp trong Markdown; chưa có file PNG kiến trúc hoặc dashboard preview ở đây.

- Sơ đồ chuẩn để đối chiếu source: [data flow](../docs/architecture/data_flow.md).
- Tổng quan ngắn: [README](../README.md).
- Kế hoạch Airflow, được tách khỏi kiến trúc đang chạy: [upgrade plan](../docs/architecture/upgrade_plan.md).

Khi thêm ảnh export hoặc screenshot, ghi ngày và môi trường/dataset sử dụng. Nếu source/flow thay đổi, cập nhật Mermaid trước rồi xuất lại ảnh để tránh lưu hai kiến trúc khác nhau.
